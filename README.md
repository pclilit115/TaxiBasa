# Տաքսու լիցենզիաների ռեեստր (նախատիպ)

Ավտոբուսային գծերով երթևեկելու թույլտվության լիցենզիաների ռեեստրի նախատիպ (նախագիծ Շ2)։

- **admin / admin** (ԵԵԿ-ի ադմինիստրատոր)՝ տրամադրում է լիցենզիա՝ ավտոմատ համարով և QR կոդով, չեղարկում է՝ նշելով պատճառը, և վերականգնում է։
- **user / 112** (Պարեկային ծառայություն)՝ միայն ստուգում է լիցենզիան հերթական համարով կամ QR կոդով։
- QR կոդը բացում է `…/TaxiBasa/#lic-0001` հասցեն։ Մուտք գործելուց հետո տվյալները բացվում են անմիջապես։
- Ժամկետը լրանալուն պես լիցենզիան ավտոմատ կերպով չեղարկվում է։

## Կարևոր սահմանափակումներ

- **Տվյալները պահվում են միայն տվյալ բրաուզերում** (localStorage)։ GitHub Pages-ում ընդհանուր տվյալների բազա չկա, ուստի ադմինիստրատորի տրամադրած լիցենզիան պարեկային ծառայողի հեռախոսում չի երևա։ Իրական աշխատանքի համար անհրաժեշտ են սերվեր և տվյալների բազա (օրինակ՝ Supabase կամ Firebase)։
- **Գաղտնաբառերը գրված են էջի կոդում** և տեսանելի են բոլորին։ Դրանք միայն առանձնացնում են դերերը և պաշտպանություն չեն ապահովում։ Իրական կիրառման համար անհրաժեշտ է մուտք սերվերի միջոցով։
- QR կոդի հասցեն փոխելու համար խմբագրեք `index.html`-ի `const SITE=` տողը։
- Լոգոների համար նախատեսված են անտեսանելի տեղեր (`logo-left.png`, `logo-right.png`)։ Տե՛ս կոդի մեկնաբանությունը։
